## 🛠️ Окруження та інструментарій
* **IDE:** Visual Studio 2022 (Windows 11)
* **Компілятор:** MSVC (Microsoft Visual C++ за допомогою Developer Command Prompt)
* **Утиліти аналізу:** `dumpbin.exe` (дизассемблювання машинного коду на Windows)
* **Контроль версій:** Git + GitHub (інтеграція через Visual Studio 2022)
